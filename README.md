 
# 💰 Finzova – AI Financial Planning Assistant

An AI-powered personal finance platform that helps users analyze their financial health, manage expenses, optimize loans, track financial goals, and receive personalized financial recommendations through an intelligent multi-agent system.

🌐 **Live Demo:** https://finzova.org

---

## ✨ Features

- 🔐 Secure Authentication (Google & Email)
- 📊 Financial Health Score (0–100)
- 💰 Income & Expense Tracking
- 📈 Expense Breakdown Dashboard
- 🎯 Financial Goal Management
- 💳 Loan & EMI Optimization
- 🤖 AI-Powered Financial Recommendations
- 📉 Goal Success Probability Analysis
- 📱 Fully Responsive Design
- 🔄 Real-time Dashboard Updates

---

## 🧠 AI Agents

Finzova uses six autonomous AI agents to analyze different aspects of a user's finances:

- Expense Agent
- Debt Agent
- Goal Agent
- Risk Agent
- Investment Agent
- Tax Agent

Each agent contributes insights that are combined into a unified financial analysis.

---

## 🚀 How It Works

1. Sign in using Google or Email.
2. Complete the financial onboarding process.
3. Enter:
   - Monthly Income
   - Expenses
   - Loans
   - Financial Goals
   - Tax Regime
4. The AI engine analyzes your financial profile.
5. Receive:
   - Financial Health Score
   - Expense Insights
   - Loan Payoff Suggestions
   - Goal Success Probability
   - Personalized Financial Recommendations
